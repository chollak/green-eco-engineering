# GREEN ECO ENGINEERING — сайт

Статический двуязычный (RU/UZ) сайт: главная + 17 страниц разделов услуг.
HTML-страницы **генерируются**, руками их править не нужно.

## Как править контент

| Что менять | Файл |
|---|---|
| Услуги, разделы, тексты разделов | `src/data/sections.mjs` |
| Телефон, адрес, ИНН, статистика, преимущества, отрасли | `src/data/company.mjs` |
| Стили | `src/assets/styles.css` |
| Скрипты (язык, меню, форма) | `src/assets/site.js` |
| Разметку главной / страницы раздела | `src/templates/home.mjs`, `src/templates/section.mjs` |

После правок — пересобрать:

```bash
node build.mjs
```

Сборка перезаписывает `index.html`, `services/*.html`, `assets/`, `sitemap.xml`, `robots.txt`.

## Структура данных раздела

```js
{
  slug: 'kabelnye-seti',      // имя файла: services/kabelnye-seti.html
  num: '10',                  // номер в каталоге
  icon: 'cable',              // ключ из src/templates/icons.mjs
  title: { ru: '...', uz: '...' },
  short: { ru: '...', uz: '...' },   // текст на карточке каталога
  intro: { ru: '...', uz: '...' },   // лид на странице раздела
  services: [{ ru: '...', uz: '...' }]
}
```

Каждый текст обязательно с парой `ru`/`uz` — переключатель языка в шапке подставляет
узбекскую версию из `data-uz` без перезагрузки страницы, выбор сохраняется в `localStorage`.
