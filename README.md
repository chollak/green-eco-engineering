# GREEN ECO ENGINEERING — сайт

Статический двуязычный (RU/UZ) сайт электромонтажной компании.
20 страниц: главная, каталог работ, 17 страниц направлений, 404.

**Продакшн:** https://chollak.github.io/green-eco-engineering/
(GitHub Pages, ветка `main`, корень репозитория)

## Сборка

```bash
node build.mjs
```

HTML в корне — **артефакт сборки**. Править его руками бессмысленно: перезапишется.
Сборка падает, если в разметку просочился абсолютный путь `/...` — на Pages сайт живёт
по подпути, такие ссылки ломаются.

## Где что править

| Что | Файл |

| Реквизиты, обязательства, отрасли | `src/data/company.mjs` |

| Стили | `src/assets/styles.css` |
| Скрипты | `src/assets/site.js` |
| Разметка | `src/templates/*.mjs` |
| Термины RU→UZ | `docs/glossary.md` |

Каждый текст — пара `{ ru, uz }`. Переключатель языка подменяет содержимое из `data-uz`
без перезагрузки, выбор хранится в `localStorage`.

**Узбекские апострофы:** `oʻ`/`gʻ` — U+02BB (ʻ), `taʼmir` — U+02BC (ʼ).
Прямых `'` и типографских `’` в узбекском тексте быть не должно.

**Стрелки и галочки** — только inline SVG из `src/templates/icons.mjs`:
глифов `→` и `✓` нет ни в IBM Plex Sans, ни в IBM Plex Mono.

## Дизайн

Направление «ПРОТОКОЛ 01–17»: страница верстается как лист исполнительной документации —
белая бумага с зелёным подтоном, hairline-линии, сквозная моноширинная нумерация,
однолинейная схема вместо фотографий, фактура в формате «параметр : значение».

Правила, которые легко нарушить при доработке:
- фотографий на сайте нет и не будет — это жанр, а не дефицит;
- инверсия ровно одна (секция `#contact`), чередования полос быть не должно;
- радиусов три: `0`, `2px` (чипы), `6px` (кнопки и поля). Единый радиус на всём — маркер шаблона;
- вертикальные отступы секций — три разных токена, не один;
- рамки карточек — `box-shadow: inset 0 0 0 1px`, не `border`;
- бесконечных анимаций нет ни одной; бары анимируются `transform`, не `width`.

## Требует заполнения клиентом

Поля со значением `null` в `src/data/company.mjs` намеренно не выдуманы —
соответствующие блоки просто не выводятся, пока их не заполнят:

- `bank` — банковские реквизиты для договора;
- `labCertificate` — номер и дата свидетельства о регистрации электролаборатории;
- `staff` — сколько сотрудников с группами III / IV / V и сколько бригад;
- `telegram` — ссылка на Telegram, если он есть.

## Требует подтверждения клиентом

Тексты содержат конкретные обязательства. Если они не соответствуют действительности,
их нужно изменить **до** публикации:

- смета за 1–2 рабочих дня;
- выезд электролаборатории за 24 часа по Ташкенту;
- гарантия на работы 24 месяца;
- аварийная служба 24/7, выезд по Ташкенту в течение часа;
- допуск к работам до 110 кВ, персонал с группами по электробезопасности до V;
- собственная электролаборатория с правом выдачи протоколов;
- участие в закупках на xarid.uzex.uz.
